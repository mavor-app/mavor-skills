# mavor-skills

Static catalog of Mavor-compatible skill bundles for the Commerce Agent.

## Catalog URL

After GitHub Pages deploy:

```text
https://<your-org>.github.io/mavor-skills/index.json
```

Mavor `app.manifest.json`:

```json
"skillCatalogs": [{
  "id": "shopify-mavor",
  "indexUrl": "https://<your-org>.github.io/mavor-skills/index.json",
  "enabled": true
}]
```

## Layout

```text
skills/shopify-admin/<skill-id>/   # Skill bundle (SKILL.md, optional scripts/, references/)
dist/                              # Generated by `npm run build` — not committed
```

## Scripts

| Command | Script | Purpose |
|---------|--------|---------|
| `npm run validate` | `scripts/validate-catalog.mjs` | Check every bundle under `skills/` (frontmatter, unique ids, no forbidden CLI text) |
| `npm run build` | `scripts/build-index.mjs` | Copy `skills/` → `dist/` and generate `dist/index.json` with `files[]` per skill |

Shared helpers live in `scripts/lib/` (`bundle-scan`, `skill-schema`, `paths`) — not run directly.

Edit skills in `skills/shopify-admin/`; do not hand-edit `dist/index.json`.
